# Engineering-core v0.8.1 local release

## Title

Engineering-core v0.8.1 — single-execution ownership for aggregate validation proofs

## Release body

v0.8.1 defines a cross-language invariant for aggregate gates such as `just ci`: each expensive proof dimension executes once unless a repeated invocation materially changes its scope, mode, inputs, environment, artifact under test, isolation boundary, or failure mode.

The validation discipline now requires expansion of aggregate dependency graphs and inspection of delegated wrappers or package commands before a gate is accepted as healthy. The rule preserves distinct lint, formatting-check, typecheck, test, artifact-build, generated-drift, packaging, and runtime-smoke proofs while rejecting equivalent transitive repetition.

The owner-use release dogfood also honors the environment-selected managed temporary directory instead of writing to hardcoded `/tmp`.

### Breaking Changes

None. Existing repository command surfaces remain owner-controlled. Repositories with accidental duplicate work should reconcile their aggregate recipes while preserving every distinct proof.
