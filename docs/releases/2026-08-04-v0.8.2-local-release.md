# Engineering-core v0.8.2 local release candidate

## Title

Engineering-core v0.8.2 candidate — agent-interaction profile and Common Lisp lane

## Release body

The local v0.8.2 candidate adds the smallest reversible `agent-interaction` catalog profile. It presets no language lane and recommends only existing disciplines, in evidence-grounded order:

1. `validation`
2. `testing`
3. `security-privacy`
4. `observability`
5. `local-first-data`
6. `specification-and-dsls`
7. `documentation`

The candidate also adds the advisory `common-lisp` language lane. It treats macros, CLOS, and the Metaobject Protocol as first-class language-extension tools; records REPL/hot-redefinition hazards for macros, compiled calls, special variables, structures/classes, and staging; and defines conservative SBCL/ASDF, dependency, test, portability, and Justfile baselines.

Agent Kernel task 4667 is the execution membrane for the `agent-interaction` profile only. That catalog addition follows bounded cross-owner G3 read-only canary evidence with an independent PASS. The separately operator-directed Common Lisp lane does not inherit that task or evidence.

Both additions remain advisory. They do not prove consumer adoption or runtime effectiveness, and this preparation does not claim a completed/tagged release or publication, define ontology, or impose mandatory policy. Consumers retain ownership of lane selection, local deviations, validation, and adoption decisions.

### Breaking Changes

None. The new Common Lisp lane adds retrievable advisory guidance, not runtime integration or enforcement.
