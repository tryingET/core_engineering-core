# engineering-core v0.9.0

## Title

engineering-core v0.9.0 — reconciled release lineage, executable adoption, and release automation

## Release body

This release reconciles the full `v0.8.0` history with the catalog/adoption PR stack and publishes the combined result as one coherent minor release. It retains the v0.8 planning, capability, evidence-reconciliation, and owner-use contracts while adding safe repository initialization and migration, catalog projections, fleet diagnostic ratchets, a checked agent skill, and opt-in TypeScript quality pilots.

The release also closes the process gap that allowed a stale `0.3.x` branch to be merged after `v0.8.0`: CI now validates stable-tag ancestry and monotonic versions, the release workflow validates and tags only commits contained in `main`, and merged automation branches are cleaned up deterministically.

### Breaking Changes

- The declared Python runtime floor is now Python 3.10.
- The package version advances from `0.8.0` to `0.9.0`; the temporary `0.3.4`–`0.3.8` stack versions were never valid successors to `v0.8.0` and are intentionally not released.
- Experimental TypeScript quality entries remain in `catalog.pilots.json`; they are opt-in and are not stable defaults.

### Verification before tag

Run from the repository root with full Git history and tags available:

```bash
uv sync --locked
uv run python scripts/check-release-lineage.py --mode ci
uv run python -m engineering_core.self_check --repo-root .
uv run python -m unittest discover -s tests -v
uv run python scripts/check-justfile-addenda.py
uv run python scripts/sync-skill-assets.py --check
uv run python scripts/dogfood-closed-loop.py
uv run python scripts/dogfood-capabilities.py
uv run python scripts/dogfood-evidence-reconcile.py
uv run python scripts/dogfood-owner-use.py
uv run python scripts/release-local.py verify --version 0.9.0
```

The automated release workflow repeats the release checks, creates `v0.9.0` only from validated `main`, builds the wheel and source distribution, and creates a GitHub Release with both artifacts.
