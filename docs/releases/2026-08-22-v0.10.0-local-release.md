# engineering-core v0.10.0

## Title

engineering-core v0.10.0 — restored post-v0.8 local line: Common Lisp lane, agent-interaction profile, and evidence records

## Release body

This release restores the durable content of the unreconciled local history line that the v0.9.0 recovery rebuild dropped: the `common-lisp` language lane, the advisory `agent-interaction` recommendation profile, the aggregate-gate proof-ownership discipline guidance, the v0.8.0 validation evidence record, the narrow-v0.8 owner-use authority ADR, the v0.8.1 local-release record, and the portable immutable remote adoption pin guidance.

The restoration was performed by cherry-picking the orphaned commits onto the reconciled `v0.9.0` main, resolving conflicts in favor of the reconciled architecture (pilots catalog overlay, release lineage checks, v0.9.0 adoption pins), and re-adapting the restored test suite to the reconciled tree. The restored tests then caught that adoption templates still taught the v0.8.0 pin; those are refreshed here and held in place by a ratchet test.

The abandoned in-place `0.8.1`/`0.8.2` version sequence is intentionally skipped: those versions were tagged locally or planned but never published, so the next legitimate published version after `v0.9.0` is `v0.10.0`.

### Breaking Changes

- The package version advances from `0.9.0` to `0.10.0`. The locally tagged `v0.8.1` and the planned `0.8.2` are not published releases and have no successor obligation.
- The restored `common-lisp` lane and `agent-interaction` profile are additive catalog entries; no existing lane, discipline, profile, or CLI behavior is removed or renamed.
- Adoption templates now document the `v0.9.0` immutable remote commit pin. Consumers pinning `v0.8.0` remain valid; only template examples moved forward.

### Verification before tag

Run from the repository root with full Git history and tags available:

```bash
python -m py_compile src/engineering_core/cli.py src/engineering_core/adoption_scan.py src/engineering_core/adoption_render.py
python scripts/check-justfile-addenda.py
python -m unittest discover -s tests
uv run engineering-core list
uv run engineering-core catalog --pretty --prefer-repo
uv run engineering-core show common-lisp --prefer-repo
uv run engineering-core scan-adoption --scope . --include-scope-root --format json --prefer-repo --max-repositories 10
uv build
```

CI additionally runs `scripts/check-release-lineage.py --mode ci` and `scripts/release-local.py verify --version 0.10.0` before the auto-release workflow tags `v0.10.0` on the exact CI-validated commit.

### Agent migration notes

No Agent Kernel state changes are required. The `agent-interaction` profile remains an advisory catalog candidate; its evidence boundary in the changelog is unchanged from the pre-reconciliation draft.
